# 李汶翰 · 个人网站

根据《简历初版.pdf》整理的静态个人网站，无需安装依赖，直接打开 index.html 即可浏览。也可将整个目录上传到静态网站托管服务。

## 内容与文件
- index.html：个人简介、学校、校园参与、实习、项目、获奖与论文、技能、特长、联系方式。
- styles.css：暖白、墨黑、橘色视觉主题与手机适配。
- script.js：项目详情、作品放大预览、滚动进度。
- works.js：个人作品配置。

## 添加作品
1. 在此目录创建 assets 文件夹，放入摄影或模型渲染图片。
2. 按 works.js 中的示例，在 portfolioWorks 数组添加图片路径、标题等信息。
3. 刷新网站。每张图片会替换一个分类预留位，点击即可放大；超过四张会继续添加。

## 信息处理说明
- 简历未附头像及作品文件，因此已移除原模板的陌生人肖像和图库照片，作品区显示“作品待补充”。
- 百度仅保留工作概述；简历里的三个空白项目不作扩写。
- Carpet 仅展示简历中明确提供的项目定位、赛道及全国 40 强成绩。
- 截至 2026-11-02，2027/2028 年的结束日期标注为预计日期或计划期间。
- 未注明年份的奖励、论文不补造年份；论文标题中的“0ld”按“Old”规范排写。
- KOS、QAC 等认证名称保留简历原称，未进行外部核验。
- 项目指标依照简历描述，未额外推算转化率或效率提升。
- 联系邮箱和电话来自简历。网站尚未部署到公网；发布前可按个人偏好调整展示信息。
- 字体使用 Google Fonts，可在无法联网时回退到本地字体；不使用外部作品图片。

## 动态人物形象
- 首屏使用本人提供的角色动画与设定图，替换原来的文字身份卡。
- assets/avatar-motion.mp4：15.1 秒静音动画，压缩为 768×768，约 698 KB；不会播放原视频音轨。
- assets/avatar-poster.jpg：视频截图，作为加载时的静态封面。
- assets/avatar-reference.png：原始角色设定图，保留在素材目录供后续使用。
- avatar.js：静音自动播放与无限循环，浏览器限制自动播放时在首次页面交互后重试。
- 该形象使用预渲染视频，不是可自由旋转的实时 3D 模型。若需拖拽旋转或骨骼动作切换，可后续接入带动画的 GLB/GLTF 文件。

## 页面交互更新
- 首屏英文：From spaces to products.
- 右下角橙底白字圆形悬浮回顶按钮，带细线圆环与悬停效果。
- 项目区向左无限循环，鼠标悬停不暂停；键盘操作、打开详情及离屏时暂停；支持左右切换和触屏横向滑动；暂停按钮已按批注移除。
- carousel.js 管理项目展示带；系统开启减少动态效果时默认不自动滚动。

## 阅读交互更新
- 回顶按钮默认小圆箭头，鼠标悬停或键盘聚焦时放大并显示文字。
- 个人简介、学校、实习、获奖默认收起；滚动进入阅读区域时向右展开，离开后保持展开。仅点击标题手动收起；手动收起后不会因滚动重开，点击标题或导航可重新展开。
- sections.js 负责浏览时自动展开与手动收起；导航点击先展开目标再定位，不影响其他已展开模块。
- 联系区标题为英文：Let’s make something great.
- 无 JavaScript 时仍可阅读全部内容；减少动态效果模式禁用展开动画。

## 系统时钟、快捷导航与动态标题
- 顶部按时 / 分 / 秒 / 年 / 月 / 日显示访问者设备的实时系统时间，每秒重新读取，遵循设备时区。
- 回顶按钮鼠标经过或停留时展开六条带文字的放射式快捷入口；键盘聚焦也可展开，Esc 关闭。触屏首次轻触展开菜单，展开后再次触碰中心按钮返回顶部。
- 快捷入口：个人简介、学校、实习经历、项目经历、获奖与成果、特长与爱好。
- enhancements.js 管理系统时钟、放射导航与英文打字动画。
- 标题末词按 great → new → intelligent → interesting → unique 顺序输入、停留、逐字删除并重复。减少动态效果模式下保持静态 great。

## 草图版导航与视觉调整
- 快捷导航按草图改为 120° 放射式结构：默认仅有六条直线与沿线文字；悬停或键盘聚焦单项时展开橙色缺口扇面。
- 中心圆仍返回顶部，沿用网站橙色/暖白/墨黑配色；为完整显示上下射线，悬浮主圆略微上移。
- 六个入口在手机端均可见，支持点击与键盘导航。
- 五项获奖沿用论文发表的橙色左竖线、分类、小标题与说明格式；内容保持不变。
- 顶部导航加入灰色半透明底色、背景模糊、柔和边框和阴影。

## 紧凑放射菜单
- 可见射线由 167 缩短至 116.9 个 SVG 单位（缩短 30%），文字同步向主圆靠近。
- ray-menu.js 管理动态角度布局：总展开范围维持 120°；选中项占 40°，其他五项各 16°，以动画向两侧让位。
- 命中区覆盖连续的环形扇区，并延伸至线条外侧；选中底板采用半透明背景与 16px 背景模糊。
- 支持鼠标悬停、键盘聚焦及快捷跳转，手机端按比例缩放。

## 首页与联系区精简
- 首屏移除大字号姓名，主标题调整为“从空间到产品”。
- 联系区减少上下留白与轨道尺寸；保留打字效果和轨道动画。
- 联系邮箱、电话、轨道线条与轨道中央文字统一为白色。

## 获奖与论文悬停展示
- 六个条目统一缩小字号和留白，间距减少为 18px。
- 默认左竖线为深灰色，鼠标悬停或键盘聚焦时变为橙色，整项平滑放大 10%，不挤动相邻条目。

## 人物卡片简化
- 移除播放、重播、角色设定按钮及播放状态文案，卡片底部仅显示“李汶翰-简介”。
- 视频使用 autoplay / muted / loop / playsinline，页面打开后自动静音循环播放，不因滚动离屏而由网站主动暂停。浏览器或设备仍可能限制后台与自动播放。

## 球面双圆环
- sphere-orbits.js 将同一球面上两个相交的正圆进行共同的三维旋转，再按透视投影绘制。
- 圆环随视角自然呈现圆形、宽椭圆、窄椭圆及接近侧面的细线，前半环更亮、后半环更淡；中央文字保持稳定。
- 原有平面椭圆旋转已停用，保留白色外圈；离屏与后台停止计算，减少动态效果偏好下显示静态投影。

## 圆环循环流畅度
- 采用 40 秒完整周期，两个旋转轴在周期内分别完成整圈，首尾位置和速度连续。
- 使用浏览器帧时间计算姿态，复用数值缓冲并连接 SVG 路径，减少每帧字符串和内存分配。
- 离屏暂停后从原进度继续，观察器重复通知不会重启动画。

## 同步圆环与实习悬停
- 圆环改为 12 秒无缝周期，两个圆环共用同一三维旋转，X/Y 轴同步等速加快。
- 实习条目缩小至 19px 标题、12px 正文，减少内边距与标签间距；鼠标悬停或键盘聚焦时整项放大 10%，前置圆点由深灰变为橙色。
